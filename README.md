# 마감 — 2세대 가계부

두 세대가 함께 쓰는 생활비를 **40:60으로 나눠 정산**하는 가계부 앱입니다.
영수증을 카메라로 찍으면 상호·금액·날짜를 읽어 자동으로 입력합니다.

아이폰 사파리에서 열고 **공유 → 홈 화면에 추가**하면 앱처럼 씁니다.

## 중요 — 이 저장소에는 가계부 내역이 없습니다

GitHub Pages 무료 등급은 **공개 저장소에서만** 동작합니다. 그래서 실제 거래 내역은
저장소에 두지 않습니다. 앱 코드만 공개되고, 기록은 **각자 폰 브라우저 안에만**
저장됩니다. 주소를 아는 사람이 접속해도 빈 앱이 보일 뿐입니다.

과거 기록은 `tools/extract.py`가 만든 복원 파일을 폰으로 옮겨
**설정 → 백업 파일에서 복원**으로 넣습니다.

## 쓰는 법

| 화면 | 하는 일 |
|---|---|
| **정산** | 누적 정산액 한 줄, 세대별 결제·부담·차액, 범주별 지출 |
| **기록** | 날짜별 목록. 항목을 누르면 수정·삭제 |
| **추가** | 영수증 스캔 / 자주 가는 곳 / 직접 입력 |
| **설정** | 백업·복원, CSV 내보내기, API 키 |

영수증 스캔에는 Anthropic API 키가 필요합니다(설정에서 입력, 폰에만 저장).
**키가 없어도 직접 입력·정산·백업은 전부 동작합니다.**

## 기록이 사라지지 않게

기록은 이 폰 안에만 있습니다. 서버에 사본이 없으므로 폰을 바꾸거나 브라우저
저장공간이 정리되면 되돌릴 수 없습니다. **설정 → 백업 파일 내려받기**를 가끔
눌러주세요. 2주 넘게 백업하지 않으면 앱이 알려줍니다.

## 개발

```bash
cd app
npm install
npm run dev      # 같은 와이파이의 폰에서도 접속 가능
npm run build
```

`main`에 push하면 GitHub Actions가 빌드해서 Pages에 배포합니다.

정산 로직을 고쳤다면 반드시 엑셀과 대조하세요:

```bash
python tools/extract.py              # 엑셀 -> data/ (읽기 전용)
cd app && npx tsx ../tools/verify.ts # 28개월 x 7개 값 대조
```

설계 의도와 엑셀 장부의 구조는 `CLAUDE.md`에 있습니다.
